В данном проекте представлен файл, который открывает большой JSON-файл (при помощи ijson) и удаляет из него мусорные или выборочные данные (используя регулярные выражения), сохраняя изменения в новый JSON-файл.

<--Структура проекта-->
Четыре JSON-файла, представленные как результат работы проекта, и основной файл UAcollect.py, который состоит из 4-ёх функций, выполняющих конкретную задачу: удаление мусорных данных, запись в конечный файл только новых данных, удаление дубликатов, поиск и выборочное удаление артефактов.


<--Демонстрационный вид проекта-->
Представлен без изменений в последнем рабочем состоянии. Были только удалены чувствительные для автора данные: например, системное имя пользователя в пути к файлам в UAcollect.py было заменено на %USERPROFILE%. Так что при осмотре проекта следует иметь ввиду, что все комментарии, код и данные не были адаптированы для просмотра сторонними лицами.


<--Происхождение проекта-->
Является частью работы по парсингу сайтов, для которой требовались валидные строки User-Agent (используются браузерами и сайтами для идентификации систем входящих пользователей и блокировки ботов). Поскольку открытые источники актуальных User-Agent всегда выдавали списки, содержащие множество устаревших строк или строк пауков, возникла необходимость в сортировке таких списков, чтобы коллекционировать только допустимые UA.


<--Цель проекта-->
Коллекционирование современных валидных UA-строк, получаемых после фильтрации мусорных списков из открытых источников. Полученные строки использовались разрабатываемыми автором автоматизированными системами для сбора открытых данных с сайтов (они же - пауки) с целью обхода их систем защиты от таких сборщиков с соблюдением политики robots.txt


<--Проблемы решённые проектом-->
1. Открытие в файле .py огромного JSON-файла приводит к длительному ожиданию или даже зависанию системы. Для решения этой проблемы используется сторонний модуль ijson, который позволяет работать с JSON-файлами любого объёма без серьёзных задержек.
2. Умение написания регулярных выражений (модуль re) помогло автору прописать алгоритм поиска мусорных строк без длинных структур if-elif-else, что также ускорило выполнение проектом задачи.
